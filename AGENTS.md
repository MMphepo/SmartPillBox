# Malawi MoH Digital TB Adherence Portal — Smart Pill Box System

Guidelines and instructions for working on this repository:

1. **Institutional Standards:** Maintain clean, professional, government healthcare styling for Malawi Ministry of Health ("Information first. Decoration second.").
2. **Three Microservices Architecture:** Keep Frontend (React/TanStack), Main Backend (FastAPI on port 8000), and Arduino IoT Server (port 8001) independent.
3. **Data Source of Truth:** Do not hardcode static demo state in production workflows. The Main Backend is the authority for application state and auth session state.
4. **Generated Code:** Do not manually edit `src/routeTree.gen.ts` as it is automatically generated by TanStack Router during build/dev.
